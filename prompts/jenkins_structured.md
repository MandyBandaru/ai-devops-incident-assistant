
# Role
Act as a senior DevOps engineer specializing in Jenkins.

# Task
Help me troubleshoot a failed pipeline.

# Context
- Stage: Build
- Environment: Linux Jenkins agent
- Recent change: Build moved to a new agent
- Console error: `mvn: command not found`

# Instructions
1. Explain the error in simple English.
2. Separate confirmed facts from possible causes.
3. Suggest safe diagnostic commands.
4. Explain what each command checks.
5. Do not assume the root cause without evidence.
6. Do not recommend changes before explaining the risks.

# Output format
1. Error explanation
2. Confirmed facts
3. Possible causes
4. Diagnostic steps
5. Recommended next step
